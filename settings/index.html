API Keys

Groq API Key

Required for audio features: Record Session, Dictate Note, and Upload Recording. Free to set up, no credit card needed.

How to get your free API key
  1. Go to console.groq.com/keys and sign in with your Google account
  2. Click Create API key
  3. Give it a name (e.g. LushNote), then click Submit
  4. Copy the key shown. It starts with gsk_
  5. Paste it in the field below and click Save Key

Stored securely in your account — available on any device you sign in with.
